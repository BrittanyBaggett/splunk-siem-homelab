
# Python File Modification Monitor Integration

## Overview

Integrated a Python-based file modification monitoring script with Splunk Enterprise to collect and analyze filesystem modification events.

The Python script uses the Watchdog library to monitor a Windows directory for changes. When a file modification is detected, the event is recorded in a log file that is collected by the Splunk Universal Forwarder.

## Tools Used

- Python 3
- Watchdog library
- Python logging module
- Splunk Enterprise
- Splunk Universal Forwarder
- Windows 11

## How It Works

1. Watchdog monitors a specified Windows directory.
2. A custom event handler detects file modifications and ignores directory modification events.
3. Python's logging module records the modified file path, timestamp, and logging severity.
4. Splunk Universal Forwarder monitors the generated `file_monitor.log`.
5. Splunk Enterprise receives and indexes the events for investigation.

## Splunk Universal Forwarder Configuration

Created an `inputs.conf` file in the Universal Forwarder's local configuration directory:

`C:\Program Files\SplunkUniversalForwarder\etc\system\local\`

Added a file monitoring input:

```ini
[monitor://C:\Lab\file_monitor.log]
disabled = 0
index = main
sourcetype = file_monitor
```

*Note: The file path above is an example. The actual configuration points to the Python project's log file.*

Restarted the Universal Forwarder using PowerShell:

```powershell
Restart-Service SplunkForwarder
```

## Verification

After configuring the Universal Forwarder, used Splunk Search & Reporting to confirm that the custom logs were being collected.

**SPL Query:**

```spl
index=main sourcetype="file_monitor"
```

The search successfully returned file modification events generated by the Python script.

### Example Log Entry

```text
2026-11-18 15:39:26,466 INFO: C:\Lab\Text1.txt | File Modified
```

This confirms that file modification events can be detected by a custom Python application, recorded locally, and forwarded into Splunk Enterprise.
